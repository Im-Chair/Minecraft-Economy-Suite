# 09　實作對照

版本 v4.0（2026-10-19）｜對照基準：`src/` 於 2026-06-07 的狀態

列出現有程式與新規格的差距，作為之後動程式的待辦清單。程式檔名寫在「位置」欄，方便之後指給開發者看。

---

## 一、可以沿用

| 功能 | 位置 | 備註 |
| --- | --- | --- |
| 錢包存在玩家資料上、死亡保留 | `capability/PlayerMoney*` | 需改成透過唯一入口加減錢 |
| 冒險者階級與 RP | `capability/PlayerReputation*`、`util/AdventurerRank` | 門檻與規格一致 |
| 懸賞每日抽樣、限時逾時扣分 | `core/BountyDrawHelper`、`core/BountyRegistry` | 抽樣機率與規格一致；需改用模組日 |
| 懸賞外部設定檔 | `config/DataConfigLoader` | 需加「同步給玩家端」 |
| 集資箱的遞減公式 | `core/ContributionRegistry` | 公式方向正確；需改成以 V 計算、所有物品可捐、取消「至少 1 點」 |
| 交易所積分定價 | `core/RoyalExchangeRegistry` | 需改成單一敏感度 |
| 動態交易稅分段計算 | `core/RoyalExchangeRegistry.calcTax` | 門檻改為 10,000／40,000 |
| 地圖畫 110 張圖與顏色轉換 | `core/MapPatternRegistry`、`util/MapColorConverter` | 製作流程需改 |
| 黑市投機品的錯開與冷卻資料 | `data/BlackMarketSpecData` | 需改為兩欄錯開更換 |

## 二、必須修改（依優先順序）

| 優先 | 問題 | 位置 | 改法（對應規格） |
| --- | --- | --- | --- |
| 1 | 交易所庫存高時買進再賣回可無限賺錢 | `RoyalExchangeRegistry` | 單一敏感度 0.6、買 ×1.10、賣 ×0.90、價格上下限（03 §5.2） |
| 1 | 交易所含綠寶石、金錠 | `RoyalExchangeRegistry` | 移除，改用 `exchange_items.json`（03 §5.1） |
| 1 | 廢品回收沒有上限 | `screen/ScrapYardMenu` | 改用統一回收規則與每日上限（02 §3） |
| 1 | 文明點數有天花板，後期時代到不了 | `core/ContributionRegistry`、`core/AgeManager` | 新晉升條件（03 §1） |
| 2 | 時代多了「工業時代」 | `util/Era` | 刪除 INDUSTRY；舊存檔若停在工業時代，讀檔時轉為商業時代 |
| 2 | 時代門檻依「當下在線人數」且人越多越高 | `core/AgeManager.getScaledRequiredCp` | 改用人數係數（00 §5） |
| 2 | 加減錢直接改餘額、沒有帳本 | 所有呼叫 `addMoney`／`removeMoney` 的地方 | 唯一入口＋帳本（01 §1） |
| 2 | 時間用「一天中的時刻」計算 | `event/ForgeEvents`、各封包 | 模組日（01 §2） |
| 2 | 背包滿時購買的物品消失 | `RoyalExchangeMenu`、`ArtisanMenu`、`DimensionalMerchantMenu` | 放不下的掉在腳下（01 §1.4） |
| 2 | 介面永不失效、不檢查距離；黑市賣出不檢查介面 | 所有 `*Menu.stillValid`、`SellTypeToBlackMarketC2SPacket`、`SellSpecToBlackMarketC2SPacket` | 01 §5.2 |
| 2 | 黑市用「清單第幾行」送請求，且清單不從伺服器同步 | `BlackMarketScreen`、`SellTypeToBlackMarketC2SPacket` | 改用物品名稱，清單由伺服器同步（01 §5.3） |
| 3 | 方塊沒有合成配方、NPC 只能用生成蛋 | `src/main/resources/data/` | 加配方與契約物品（01 §4、§5） |
| 3 | NPC 會被打死 | `entity/*` | 無敵、不可推動（01 §5.1） |
| 3 | 懸賞板沒有掉落表 | `data/economycore/loot_tables/blocks/` | 補 `bounty_board.json` |
| 3 | 黑市大宗價格「每個 5 希爾」 | `core/BlackMarketRegistry` | 改為 V × 0.50 × 收購飽和（02 §3.2） |
| 3 | 投機品池放了可量產物品，且三天整批更換 | `core/BlackMarketRegistry`、`data/BlackMarketSpecData` | 02 §4 |
| 3 | 購買也課交易稅 | `ArtisanMenu`、`RoyalExchangeMenu`、`DimensionalMerchantMenu` | 購買不課稅（03 §6） |
| 3 | 工匠賣沒有功能的物品（掛鎖、萬能鑰匙）與原版雜物 | `core/ArtisanShopRegistry` | 只上架有功能的物品（03 §7） |
| 3 | 次元商人販售四大權證與「君王用的證」 | `core/DimensionalMerchantRegistry` | 改為 03 §10 清單；刪除「君王用的證」 |
| 3 | 地圖畫：藍圖抽卡解鎖、之後無限免費產圖 | `item/MapArtBlueprintItem`、`network/packet/GenerateMapC2SPacket` | 03 §9 |
| 4 | 時代、物品等各種數值寫死在程式中 | 多處 | 改讀設定（08） |
| 4 | Forge 範例殘留 | `Config.java`、`gradle.properties` 的 `com.example.examplemod` | 移除範例、改套件名稱 |
| 4 | 只有繁中語言檔、介面文字寫死 | `lang/zh_tw.json`、各 `*Screen` | 若要公開發布才處理 |
