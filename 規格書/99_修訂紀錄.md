## v4.1（2026-11-05）

依 v4.0 審查結果修正。新增的數字都是初始值，尚未經實際遊玩驗證，可在設定檔調整。

| 之前 | 現在 | 原因 |
| --- | --- | --- |
| 交易所賣出只限每日數量 | 另加每人每日賣出收入上限 6,000／10,000／15,000 | 賣價有 0.54V 的下限，單人賣地獄之星每天可得約 172,800 希爾 |
| 收購飽和與捐獻遞減按物品 ID 累計 | 按物品族累計（〈02〉1.6） | 同一批圓石做成多種型態就能躲開遞減；30 種型態時回收多 56%、捐獻多 35% |
| 投機品池含可量產的物品 | 移除其他唱片、三叉戟、鸚鵡螺殼、鞍、命名牌、鐘、盔甲紋飾模板、皮革馬鎧；規則補上村民交易與複製配方 | 這些物品可由農場、村民或複製大量取得 |
| 基準表只有節錄 | 補齊原版原料與固定價物品，並新增海綿等 V | T4 原本無法照做；海綿是交易所品項卻沒有 V |
| 配方推算缺鍛造台公式與其他配方類型 | 補鍛造台公式；高爐等視為熔煉；其他模組配方盡量讀取；新增模組預設與 `item_values_unresolved.json` | 模組機器配方算不出來時，產物多半只值稀有度預設 |
| 自動懸賞要求物品單價落在價值帶內 | 任務總價值約等於價值帶中位數，數量上限 256，無候選時從缺 | 高階價值帶幾乎沒有符合的原版物品 |
| 交易稅入帳方式未定義 | 先存稅前金額，再以 `SALE_TAX` 扣稅 | 否則帳本加總與餘額對不上 |

| 錢包只寫死亡不損失 | 含從終界返回；T2 加入處理與驗收 | 舊程式返回時不複製資料 |
| 城邦內作物生長 50%、生物生成 70% 機率被取消 | 取消此限制 | 與「豐收」「安居」赦令衝突；回收上限與物品族已控制農場收入，這條只會懲罰自己的基地 |
| 公會未定義經驗曲線，每升一級 1 點卻寫最多 20 點 | n 級升 n＋1 級需 n × 100 經驗；建立時得 1 點，共 20 點 | 補定義、修正矛盾 |
| 懸賞抽取範圍超出 F～S 未定義 | 超出部分併入本階級；明定上一級為較高階 | 補定義 |
| 希爾不得轉移，但彩池會把他人的錢分給中獎者 | 明列樂透與鬥技場為唯一例外 | 修正矛盾 |
| T3 未列 `Money.round`；T9 需要 `RankService` 卻到 T10 才提到 | T3 加入；T9 建立 `RankService` | 補足工作順序 |

## v4.0（2026-10-19）

取代 2026-04 的八份 PDF（設計總綱 v2.0、經濟核心 v3.0、城鎮發展 v3.0、黑市 v2.0、玩家公會 v2.0、休閒與博弈 v2.0、證券交易所 v2.0、君主城邦 v2.0）。舊檔已移到 `待刪除/` 資料夾。

同日補充：新增〈10 共用定義〉（各功能共用的程式名稱、服務、事件、存檔規則）與〈11 第一階段工作清單〉（含合成配方與驗收方式），讓規格可以直接交給開發者照做。

本次依三個核心目標全面檢討：不通膨、所有物品都有價值、單人多人都能玩。下表逐項列出「之前怎麼寫、現在改成什麼、為什麼」。

### 架構與總綱

| 之前 | 現在 | 原因 |
| --- | --- | --- |
| 七個獨立模組＋共用介面模組 | 單一模組，內部分資料夾 | 個人專案沒有「只裝其中幾個」的需求，拆分只增加成本；現有程式本來就是單一模組 |
| 設計原則五條（彈性、意義、敘事、兼容、架構） | 三個核心目標，附優先順序 | 讓取捨有明確依據 |
| 首都「天空之城」自動生成，NPC 與設施都在首都 | 取消首都；設施靠合成、NPC 靠契約，到對應時代才能用 | 舊規格從未定義首都怎麼生成，是隱藏的大工程 |
| 時代英文名 COMMERCIAL、CELESTIAL；程式另有 INDUSTRY | 沿用程式名稱 COMMERCE、STAR，刪除 INDUSTRY，共 5 個時代 | 改名會讓舊存檔讀不到時代、默默回到拓荒時代 |
| 人數縮放：Max(玩家數^0.7, 0.15) | (活躍人數÷20)^0.7，限制在 0.15～1.0 | 舊公式代入後與範例不符（1 人得 1.0，20 人得 8.14） |
| 用「當下在線人數」 | 用「最近 7 日登入過的人數」 | 避免挑人少時捐獻降低門檻 |
| 未定義「一天」怎麼算 | 模組日：只會前進，不受指令調時間影響 | 舊程式用一天中的時刻，調時間會讓任務永不到期、額度重置 |
| 加減錢 API 有「交易事由」但未實作 | 唯一入口＋帳本＋管理員報表 | 沒有帳本就無法判斷是否通膨 |

### 回收（原：廢品回收站、黑市大宗、萬物收購商）

| 之前 | 現在 | 原因 |
| --- | --- | --- |
| 三個系統各自定價：廢品固定極低價、黑市「每組」5 希爾、萬物收購商另計 | 合併成一套：每種物品有基準價值 V，回收商 0.3V、黑市 0.5V，全服賣越多價格越低 | 同時滿足「所有物品有價值」與「不通膨」 |
| 廢品回收站無每日上限 | 回收商與黑市合計每日上限，依時代 1,500～15,000 | 舊程式中圓石生成器就是印鈔機 |
| 黑市上限 15,000 固定 | 回收每日上限依時代遞增，星辰時代為 15,000；投機品另有 5,000 | 前期收入規模較小，上限跟著時代成長 |
| 其他模組物品由萬物收購商另外處理 | 以配方自動推算 V，推不出依稀有度，皆可回收、捐獻、收藏 | 「所有物品有價值」 |
| 投機品每日刷新、每種持續 3 天 | 兩欄錯開更換，每種 3 天 | 原文「每日刷新」與「持續 3 天」互相矛盾 |
| 投機品收購價固定 1,500 | V × 3 | 跟物品本身價值連動 |
| 程式的投機品池含鐵錠、火藥等 | 只能放無法量產的物品 | 原規格本意 |

### 城鎮發展

| 之前 | 現在 | 原因 |
| --- | --- | --- |
| 時代只看文明點數，只能捐 5 種建材 | 四類條件：文明點數、捐獻希爾、階級人數、遊戲里程碑；所有物品都能捐 | 舊程式捐獻總量有天花板，後期時代到不了；前期也沒有花錢的地方 |
| 捐獻每次至少 1 點 | 以小數累計 | 舊規則讓一個一個捐反而划算 |
| 交易所買賣敏感度 0.8／0.5 | 單一敏感度 0.6，買價固定比賣價高 22% | 舊公式在庫存高時可無限套利 |
| 交易所含綠寶石（程式）、金錠（程式） | 移除 | 綠寶石違反脫鉤原則；金錠可大量生產 |
| 交易所庫存只靠玩家買賣變動 | 每日往理想庫存回歸 10% | 避免一次灌爆後永遠失衡 |
| 動態交易稅門檻 50,000／200,000 | 10,000／40,000 | 回收有每日上限後，舊門檻幾乎碰不到 |
| 程式對購買也課稅 | 只對賣出課稅 | 與規格原意一致 |
| 博物館：完成展廳得「每日年金」 | 首次收錄得 0.5V（一次性），分館收齊得分館總值 20% | 年金是永久進錢管道；一次性獎勵總量有限 |
| 博物館收藏：生物數據、考古、特殊漁產 | 所有 V > 0 的物品，每個其他模組自成一館 | 「所有物品有價值」 |
| 地圖畫：本文「全部公開、扣材料」vs 附錄「藍圖隨機解鎖」；程式採後者且免費無限產圖 | 全部公開、每張扣藍圖與染料 | 保留消耗設計 |
| 地圖畫主題含「動畫角色」 | 移除 | 著作權風險 |
| 石碑急救：手持右鍵自動判斷、0.5 秒確認、20 萬 | 服務頁按鈕、1 秒確認、餘額 5%（至少 2,000） | 避免誤觸；費用在各時代都有感 |
| 富人稅依賴證券交易所且列為擴充 | 財富持有稅只看錢包，第二階段，可關閉 | 證券交易所暫緩 |
| 次元商人（程式）賣四大權證 | 不賣權證 | 權證是史詩任務的成果 |
| 尼德霍格首領單人縮放 | 保留 | — |
| 百工議會、財經新聞 | 暫緩 | 需要多人與大量內容 |
