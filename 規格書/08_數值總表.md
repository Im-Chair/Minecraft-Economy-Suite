# 08　數值總表

版本 v4.0（2026-10-19）

所有可調整的數值集中在這裡。程式中**不得**把這些數字直接寫死在各處；一律讀取設定，改數值只改設定檔一處。

- 單一數值放在 `config/economycore/economy.toml`（下表「設定名稱」就是檔案裡的名稱）。
- 清單類資料放在 `config/economycore/` 下的 JSON 檔（最後一節）。
- 規格書其他篇章若與本表不一致，**以本表為準**。
