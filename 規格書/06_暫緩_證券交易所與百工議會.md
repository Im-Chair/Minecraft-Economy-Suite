# 06　暫緩：證券交易所、百工議會、財經新聞

版本 v4.0（2026-10-19）｜狀態：暫緩，不排入任何開發階段

本篇保留舊規格的構想，並記錄「重新啟動前必須先解決的問題」。在問題解決前不實作。

---

## 第一章　暫緩原因

| 原因 | 說明 |
| --- | --- |
| 單人等於印鈔 | 交易對象是系統，玩家賺的每一分錢都是系統新發的。只要漲跌可預測（真假新聞、內線情報、城主自己頒布的赦令），就是穩定的進錢管道，違反「不通膨」 |
| 核心樂趣需要多人 | 真假新聞的樂趣是「玩家之間的資訊落差」，單人沒有對手 |
| 依賴鏈太長 | 股價依賴百工議會，百工議會依賴公會與多人捐獻，財經新聞需要至少 80 條內容 |

---

## 第二章　保留的構想

- **標的**：五種村民職業指數（鐵匠、農夫、圖書管理員、屠夫、牧師）。不存在玩家發行的股票。
- **價格三層**：長期趨勢（相關物資的回收量、懸賞完成數）、每日小幅隨機波動（±1.5%）、新聞衝擊（分散到多天施加）。
- **單日漲跌上限 ±10%**。
- **歷史價格**：每支股票每天一筆收盤價與成交量，完整保留。
- **介面**：先做 7 日收盤價列表與漲跌箭頭，K 線圖之後再做。
- **百工議會**：各職業的影響力由玩家的懸賞（行為）與捐獻（財富）累積，每 28 個模組日選出「執政職業」。
- **個人贊助**：捐錢給某職業累積贊助等級；最高級需每月支付維護費，付不出就降級。
- **財經新聞**：每天抽一則，真假各半；同一主題 7 天內不重複；至少 40 組主題（真假各一）；可由設定檔擴充。

---

## 第三章　重新啟動前必須解決的問題

| 問題 | 舊規格的狀況 | 解決方向 |
| --- | --- | --- |
| 錢從哪來 | 玩家賺的錢由系統憑空產生 | 改成「買入時付的錢進入該股票的資金池，賣出時從資金池付款」；資金池不足時賣價打折，系統永不淨支出 |
| 股利來源 | 兩個互相矛盾的公式，其中一個憑空生錢 | 只保留「從交易稅與持有稅收入中撥一部分」 |
| 熔斷 | 熔斷門檻與漲跌上限同為 ±10%，等於碰到上限就停盤；價格一天只算一次，不存在日內波動 | 刪除熔斷，只保留漲跌上限 |
| 交易時點 | 白天以舊價格成交，新聞公布後可以用舊價格搶先買 | 所有買賣一律在下一個開盤以新價格成交 |
| 城主自己頒布赦令 | 城主知道赦令會影響哪支股票，等於內線交易：持股 1 億、赦令 +3% 就賺 300 萬，赦令只花 25 萬 | 頒布赦令的城主在赦令生效期間不能買賣受影響的股票 |
| 內線情報的維護費 | 「設為理論收益的 30%」無法計算 | 改為固定金額或依持股市值的比例 |
| 股票清單 | 共用類型只有 5 種職業，範例卻出現「工具匠」「礦工」股 | 以 5 種職業為準 |
| 單日上限數字 | 證券篇寫 ±10%，城邦篇寫「全局新聞單日上限 ±8%」 | 統一 ±10% |
| 單人模式 | 沒有資訊落差的對手 | 若無法設計出單人樂趣，就做成「活躍人數 ≥ 3 才開放」的多人附加功能 |
